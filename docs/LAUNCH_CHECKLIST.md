# Launch Checklist

## Roblox account
- [ ] Publish Power Islands as an experience.
- [ ] Confirm the correct owner/group.
- [ ] Add the numeric owner Roblox UserId to `GameConfig.AdminUserIds`.
- [ ] Create passes and paste IDs into `GameConfig`.
- [ ] Create Developer Products and paste IDs into `GameConfig`.
- [ ] Create the optional subscription and paste its `EXP-` ID.
- [ ] Configure private servers if desired.
- [ ] Complete Roblox maturity/content questionnaire and required experience settings.

## Data and security
- [ ] Enable Studio API access only on a safe test experience.
- [ ] Verify new-player data loads.
- [ ] Verify an old Phase 1/2 save reconciles with new fields.
- [ ] Verify leave/rejoin persistence.
- [ ] Test receipt processing in a published test place.
- [ ] Test trade cancellation and disconnect behavior.
- [ ] Test rapid remote-action spam.
- [ ] Confirm admin commands reject non-admin users.

## Gameplay
- [ ] Collect Energy.
- [ ] Upgrade Power.
- [ ] Hatch and equip companions.
- [ ] Complete all three starter quests.
- [ ] Unlock all six worlds.
- [ ] Verify world reward multipliers.
- [ ] Defeat Jungle Titan with one and multiple players.
- [ ] Rebirth.
- [ ] Claim a daily reward.
- [ ] Redeem each launch code once.
- [ ] Create/join/leave a party.
- [ ] Gift Energy.
- [ ] Complete and cancel companion trades.
- [ ] Trigger each live event.

## Devices
- [ ] Android phone
- [ ] iPhone/iPad
- [ ] Windows keyboard/mouse
- [ ] Xbox/PlayStation controller if targeting console
- [ ] Low-end device performance test
- [ ] UI test at small and large resolutions

## Store and discovery
- [ ] Upload final game icon.
- [ ] Upload at least three strong thumbnails.
- [ ] Add store description.
- [ ] Add update notes.
- [ ] Configure localization if targeting non-English audiences.
- [ ] Add launch promo code to social posts.
- [ ] Run a small acquisition test only after retention looks healthy.

## Go/no-go metrics
Track:
- First-session completion of first Energy collection
- First Power upgrade
- First companion hatch
- 10-minute play rate
- Day-1 return rate
- Jungle unlock rate
- Rebirth rate
- Shop opens
- Purchase conversion
- Spend days
- Party/co-play usage
