# Phase 2 — Companions, Jungle, Quests and Rebirth

Phase 2 expands the first vertical slice into a real progression loop.

## Added

- Starter Egg costing 250 Energy
- Five companion rarities from Common to Mythic
- Automatic equip for up to three companions
- Companion Energy multipliers
- Jungle Island with 5x Energy rewards
- 5,000 Energy Jungle unlock portal
- Return portal to Starter Island
- Three starter quests with automatic Energy rewards
- Rebirth altar
- Power Crystal rewards
- Rebirth scaling
- Expanded mobile HUD with pet boost, quest progress and Jungle status
- Existing Phase 1 saves remain compatible through profile reconciliation

## Current loop

Collect Energy → buy Power → hatch companions → finish quests → unlock Jungle → earn faster → reach rebirth requirements → earn Power Crystals → repeat.

## Next build

Phase 3 should add a proper companion inventory/equip screen, visual pet followers, Jungle boss, daily rewards, achievements, game passes/developer products, sound/FX and analytics events.
