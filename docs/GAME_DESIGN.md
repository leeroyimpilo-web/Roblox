# Power Islands — Game Design Foundation

## Product goal
Create a polished, mobile-first Roblox experience with strong retention, social play, progression, and legitimate monetization.

## Core gameplay loop
1. Collect Energy.
2. Upgrade Power.
3. Build and improve the player's base.
4. Unlock the next world.
5. Collect and evolve companions.
6. Defeat bosses and complete quests.
7. Rebirth for permanent Power Crystals.
8. Repeat with faster progression and harder goals.

## Monetization philosophy
Players must be able to enjoy and progress through the core game for free. Monetization should focus on convenience, cosmetics, prestige, optional boosts, and clearly defined products rather than misleading "free Robux" claims.

## First vertical slice
The first playable build should contain:
- Starter Island
- Energy pickups
- Power upgrade station
- Persistent saving
- Mobile HUD
- One companion
- One quest
- One boss placeholder
- One rebirth test path
- Shop shell with placeholder product IDs
