# Power Islands

Power Islands is a Roblox simulator + tycoon + adventure game built around a fast progression loop, social play, companions, live events, rebirths, and legitimate Roblox monetization.

## Core loop

**Collect → Upgrade → Build → Unlock → Discover → Rebirth → Repeat**

## Phase 1 — playable now

The repository currently includes a first playable vertical slice:

- Procedurally generated Starter Island
- 12 collectible Energy nodes using mobile-friendly ProximityPrompts
- Server-authoritative Energy rewards
- Power upgrade station with scaling costs
- Persistent player profiles with DataStore reconciliation
- Autosaving and shutdown saves
- Responsive mobile HUD for Energy, Power and Power Crystals
- Client toast feedback
- Six-world progression configuration
- Service-based architecture ready for companions, quests, rebirths and monetization

## Development setup

This project uses a Rojo-friendly source tree.

1. Install Roblox Studio.
2. Install Rojo (CLI and Studio plugin).
3. Clone this repository.
4. From the repository folder run `rojo serve`.
5. In Roblox Studio open a blank Baseplate, open the Rojo plugin, and connect.
6. Press **Play**. The Starter Island is generated by the server automatically.

For DataStore testing in Studio, enable **Game Settings → Security → Enable Studio Access to API Services** only for a test/published experience you control.

## Security model

Currency balances and upgrades are calculated on the server. The current playable loop does not trust client-supplied reward amounts or purchase costs. Energy collection is proximity-validated and rate-limited per node/player.
